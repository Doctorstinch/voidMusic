# VoxSong — AI Song Creator

Free prototype for creating AI songs with custom voices, genres, and lyrics.

## Live Demo
After enabling GitHub Pages, your site will be at:
`https://YOUR_USERNAME.github.io/voxsong/`

## How to use
1. Choose a male or female voice
2. Select a genre
3. Adjust Tone, Pitch, Bass, Treble
4. Write lyrics
5. Tap Generate Song
